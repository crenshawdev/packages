jcrenshaw.dev APT & RPM repos

Install jcrenshaw.dev apps as .deb, .rpm, or flatpak and get updates through apt, dnf, or flatpak. Add the repo once — everything else works like any other package on your system.

Add the repo

Debian / Ubuntu

curl -fsSL https://pkg.jcrenshaw.dev/jcrenshaw.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/jcrenshaw.gpg
echo "deb [signed-by=/usr/share/keyrings/jcrenshaw.gpg] https://pkg.jcrenshaw.dev/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/jcrenshaw.list
sudo apt update

Fedora

sudo curl -fsSL -o /etc/yum.repos.d/jcrenshaw.repo \
  https://pkg.jcrenshaw.dev/rpm/jcrenshaw.repo

Flatpak (COSMIC apps)

flatpak remote-add --if-not-exists --from jcrenshaw \
  https://pkg.jcrenshaw.dev/flatpak/jcrenshaw.flatpakrepo

The repos are GPG-signed; your package manager verifies every download for you.

Install an app

sudo apt install __EXAMPLE_PKG__    # Debian / Ubuntu
sudo dnf install __EXAMPLE_PKG__    # Fedora
flatpak install jcrenshaw com.vintagetechie.CosmicExtAppletTempest    # Flatpak

Available packages:

    __PACKAGE_LIST__

Updates come through your usual sudo apt upgrade / sudo dnf upgrade.

Remove the repo

# Debian / Ubuntu
sudo rm /etc/apt/sources.list.d/jcrenshaw.list /usr/share/keyrings/jcrenshaw.gpg

# Fedora
sudo rm /etc/yum.repos.d/jcrenshaw.repo

# Flatpak
flatpak remote-delete jcrenshaw
